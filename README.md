# openscap-beginner-guide
A simple guide for getting to know and hardening with openscap-scanner using cis benchmarks

in this repo i have shared some of my personal experience from using openscap-scanner for hardening servers and workstation using ubuntu24 

in every folder there will be a report for the actions done on that VM using oscap and the intended cis benchmark profile and the pre and post hardening result 

i have also listed a req files that are the essential requirements for installing this tool and all its dependencies on any .deb machine and once downloaded can simply be installed using either:

`sudo apt install $PATH/*.deb`

or

`sudo dpkg -i $PATH/*.deb`

if you are currently in that directory replace $PATH with ./
